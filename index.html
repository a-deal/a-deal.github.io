career.log

My work keeps taking me to places where software has to survive contact with the world: identity systems used by millions, autonomous tractors moving through fields, sensor data from industrial equipment, edge ML without reliable cloud connectivity, and health data that has to become action.

I build the integration layer between technical capability and dependable use: full-stack products, evaluation, data operations, operator workflows, and the evidence people need before they trust a system.
